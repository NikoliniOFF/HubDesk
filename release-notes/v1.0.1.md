## 🧩 HubDesk для Windows 1.0.1

**Скачать:** `HubDesk-1.0.1-win64.zip` ниже (или постоянная ссылка `HubDesk-win64.zip`). Распакуйте и запустите `HubDesk.exe`.

### Что нового
- **Если у вас HubDesk 1.0.0, один раз обновите его вручную:** закройте HubDesk, скачайте этот архив и запустите новый `HubDesk.exe` — он сам заменит старую копию в `%LOCALAPPDATA%\Nikolini\HubDesk` (или нажмите «Установить» в синей полосе). В 1.0.0 самообновления ещё не было — дальше HubDesk обновляется сам
- HubDesk обновляется сам: когда выходит новая версия, сверху появляется плашка «Обновить» — он скачает её, проверит SHA-256, заменит себя и перезапустится. Выключается в «О HubDesk» → «Обновления HubDesk»
- Больше никакой ошибки «GitHub ответил 403»: версии и новости берутся с обычных страниц GitHub без лимита запросов, а результат запоминается
- Вкладка «Новости» больше не зависает на «Загружаю…»: если загрузить не вышло — понятное сообщение и кнопка «Повторить», если новостей нет — так и написано
- В «О HubDesk» — ссылки на сайт, новости и все выпуски
- Новые значки SnapDesk, DockDesk и IslandDesk на сайте и в README

### Исправлено
- «GitHub ответил 403» на всех программах после нескольких нажатий «Проверить снова»
- Бесконечное «Загружаю…» на вкладке «Новости»
- Если GitHub просит подождать, HubDesk молча повторит проверку позже, а последние известные версии и новости остаются на экране

### Подробнее
- Сеть — только GitHub: страницы `releases/latest` и `releases/download` (файл `.sha256` рядом с архивом), лента обсуждений `discussions.atom` и `apps.json` этого репозитория. Сама по себе проверка — не чаще раза в 30 минут.
- Последние найденные версии и новости лежат в `%LOCALAPPDATA%\HubDesk` и показываются сразу, ещё до ответа GitHub.
- После самообновления HubDesk убирает старый файл `HubDesk.old.exe` и обновляет версию в «Параметры → Приложения».

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
