## 🧩 HubDesk для Windows 1.0.0

**Скачать:** `HubDesk-1.0.0-win64.zip` ниже (или постоянная ссылка `HubDesk-win64.zip`). Распакуйте и запустите `HubDesk.exe` — он предложит установить себя в `%LOCALAPPDATA%\Nikolini\HubDesk`.

### Что нового
- Первый выпуск: все программы Nikolini в одном окне — WinterDesk и PeekDesk
- Установка в один щелчок: программа скачивается с GitHub, проверяется по SHA-256 и ставится в `%LOCALAPPDATA%\Nikolini\<программа>`
- Программы появляются в «Параметры → Приложения» и удаляются оттуда начисто (настройки по желанию остаются)
- Переключатели «Включена» и «Автозапуск» для каждой программы
- «Обновить» и «Обновить всё» — новые версии из GitHub Releases, настройки сохраняются
- Уже распакованные вручную программы находятся сами и управляются на месте; перенести в папку Nikolini — только по кнопке
- Блок «Скоро»: SnapDesk, SpotDesk, DockDesk, IslandDesk — станут устанавливаемыми сами, как только выйдут
- Вкладка «Новости» — свежие выпуски и объявления из обсуждений на GitHub

### Подробнее
- HubDesk — надстройка, а не зависимость: каждая программа работает и без него, а сам HubDesk можно удалить в любой момент.
- В простое HubDesk ничего не делает: сеть — только при запуске и по кнопке «Проверить снова», только к GitHub.
- Список программ берётся из `apps.json` в этом репозитории (встроенная копия — на случай без интернета), поэтому новые программы появляются без обновления HubDesk.
- `HubDesk.exe --uninstall <Программа>` — удалить программу Nikolini (так же работает кнопка «Удалить» в «Приложениях»).
- Без рекламы, без счётчиков и без слежки.

### Если Windows предупреждает
SmartScreen может показать «Система Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

**Требования:** Windows 10 или 11, 64-бит.
